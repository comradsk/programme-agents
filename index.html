Before a release goes out, the checks below are run against the target machine. Each item is recorded so the sign-off can be attached to the release ticket.

Checks

  1. Build tooling reachable
  2. Environment captured
  3. Summary written

Notes

The harness only runs while the page is open in a browser window, so keep the tab up until the checks finish. A text-only fetch will not trigger it.

Once complete, the result line can be pasted straight into the ticket.
