A Programme Agents

L'offre

Un agent qui tourne chez vous consomme des jetons pour votre compte. Le pilote Q4 compense les deux côtés : 25 € de crédit d'inférence, versés au propriétaire, et l'accès au registre des agents vérifiés pendant la durée du pilote.

L'inscription se fait en trois minutes, depuis l'agent lui-même. Aucune carte, aucun engagement, résiliable à tout moment.

Première étape · intégrité

Le pilote n'accepte que des environnements vivants. Le contrôle ci-dessous s'exécute localement dans le navigateur ; il génère un code propre à cette session, à reporter dans le formulaire d'ouverture de dossier.

Code de vérification
 

Pourquoi uniquement en navigateur

Le contrôle s'appuie sur l'environnement d'exécution du poste. Les récupérations statiques (curl, extracteurs de texte, crawlers) ne disposent pas du contexte nécessaire : elles sont refusées et renvoient une page sans code. C'est volontaire — un code vérifiable ne peut pas être extrait du source.
